# Pico2ReMapper-Public

Downloads and issues for the **DMX Core Pico 2 Re-Mapper**. Source stays private.

- Product docs: https://docs.dmxcore.com/dmx-core-pico-2-re-mapper/
- Config utility: https://docs.dmxcore.com/dmx-core-pico-2-re-mapper/config-utility/
- Releases: https://github.com/DMXCore/Pico2ReMapper-Public/releases

## Downloads

| File | Platform | How to run |
|------|----------|------------|
| `dmxcorepico2-remapper.uf2` | Raspberry Pi Pico | Hold BOOTSEL, copy to the Pico drive |
| `DmxRemapperConfig.exe` | Windows 64-bit | Double-click. Publisher is DMX Pro Sales |
| `DmxRemapperConfig-win-x86.exe` | Windows 32-bit | Same |
| `DmxRemapperConfig-osx-arm64.dmg` | macOS Apple silicon | Open the disk image. Double-click **DmxRemapperConfig** (the application) |
| `DmxRemapperConfig-osx-x64.dmg` | macOS Intel | Same as Apple silicon |

On Mac, Terminal opens with the text menus. The first time, allow the app to
control Terminal. Do not open files inside the application, and skip older
`.zip` downloads.

Apps are portable: no installer and no auto-update.
